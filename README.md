# A股猎手｜手动随时运行版

本版本不设置定时任务。用户在 GitHub Actions 点击 **Run workflow** 后立即启动一次扫描；不限制周一至周五。程序每次启动都会重新请求当时可获取的行情数据。

## 运行方式

- A股交易时段：获取全市场最新快照；价格参考实时快照，技术指标主要基于最近已完成日线。
- 非交易时段、午休或盘后：读取最近一次已完成日线，并明确标记数据日期，不把旧收盘价伪装成实时行情。
- 接口不可用或关键数据获取失败：生成错误报告并让 GitHub Actions 显示失败，不把数据故障误报成“没有股票符合条件”。

## 配置

`config.json` 是实际运行配置，包含并发数、请求超时、历史数据天数、候选数量、评分门槛、价格/涨幅/成交额范围及学习参数。修改后下次手动运行生效。

## GitHub 部署

1. 将本目录文件放入仓库根目录，保留 `.github/workflows/manual-scan.yml`。
2. 确认工作流文件已提交到仓库默认分支，GitHub 才会显示手动运行入口。
3. 打开仓库的 **Actions** → **A股猎手-手动随时运行** → **Run workflow** → 选择分支 → **Run workflow**。
4. 报告和学习数据写入 `reports/`，工作流会尝试提交回本次运行的分支。

## 报告位置

- `reports/daily/日期_时间/`：每次运行独立报告、候选、状态。
- `reports/signals/`：历史信号。
- `reports/learning_outcomes.json`、`reports/learned_rules.json`：复盘样本与学习规则。
- `reports/raw/`：复盘用原始分钟线。

## 重要说明

这是研究筛选工具，不连接券商、不自动下单。行情接口可能延迟、限流或临时失效；盘中实时价格不等于可成交价格。评分不是胜率或收益保证。非交易时段只能使用最近可用数据。
