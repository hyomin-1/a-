# 14:30 尾盘隔夜筛选与次日复盘

这份独立研究脚本按你的目标改写：北京时间14:30启动，14:50左右拿到候选，买入后在下一交易日出现扣除成本后的正溢价时考虑退出，并复盘上一交易日未达目标的候选。没有接入券商，也没有安装每日自动运行任务。

**当前交付是可检查的研究实现。通过了离线逻辑测试，尚未完成联网行情联调、历史策略回测或实盘成交验证；不能据此宣称已经能稳定赚钱。**

## 一次运行的流程

| 时间（北京时间） | 程序动作 |
|---|---|
| 14:30起 | 核对交易日历、获取全市场快照，复盘上一交易日的最终候选 |
| 最晚14:43 | 对最多60只初选股做分钟线与历史趋势分析；超时任务终止 |
| 14:47 | 刷新全市场快照、市场上涨占比及基础过滤 |
| 14:48起 | 对初筛靠前的最多8只再次拉取分钟线，不沿用14:30价格 |
| 14:49:10 | 终止剩余网络任务，保留已完成且仍新鲜的结果 |
| 目标14:50前 | 写出最多3只候选及报告；数据不足时允许0只 |

这是程序设计的时间预算，不是实时操作系统级的交付保证。电脑睡眠、断网或系统阻塞仍会影响时间。最终报告若已过14:50，候选作废。初筛无候选、非交易日或接口故障时会提前给出空结果与原因。

## 安装和运行（Mac）

建议使用Python 3.11或3.12，安装依赖后运行；请不要使用macOS自带、没有这些依赖的旧Python解释器。

在终端进入解压后的ashare_1430文件夹：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python engine.py --wait
```

`--wait`等待**今天**14:30，只运行一次。14:30—14:43之间也可以执行`python engine.py`立即开始；越晚启动，初筛覆盖可能越少。错过14:43后拒绝运行，不会用盘后数据伪装成尾盘选股结果。每天运行需要你再启动脚本，当前没有自动设置系统定时任务。保持电脑唤醒。

输出位于程序旁的`reports/daily/YYYY-MM-DD/report.md`和`picks.csv`。Markdown报告可用文本编辑器查看；CSV可导入Excel。输出列名为英文，主要含义：

| 字段 | 含义 |
|---|---|
| code / name / score | 股票代码、名称、研究评分（不是胜率） |
| signal_time / received_at | 最新已完成分钟线时间 / 请求完成时间 |
| reference_price | 分钟收盘参考价，不是真实委托报价 |
| entry_proxy_price | 加上估算买入滑点后的研究入场价 |
| momentum15_pct | 最近15分钟涨跌幅 |
| above_vwap_pct | 相对日内分时成交均价偏离 |
| learning_penalty | 历史同类特征产生的风险扣分 |
| valid_until | 信号有效期限；临近到期仍须重新核实盘口 |

## “有溢价就跑”的明确口径

默认目标是**扣除估算买卖成本和滑点后，净收益严格大于0%**，不等固定+3%。

- 研究入场价 = 入选分钟收盘价 × (1 + 买入滑点率)。
- 研究净收益% = [退出分钟收盘价 × (1 − 卖出滑点率) ÷ 研究入场价 − 1] × 100 − 往返费用%。
- 复盘按下一交易日09:31起的已完成分钟收盘价逐分钟检查；首次正净溢价触发退出代理。不开启9:25集合竞价成交假设，不取次日最高价充当卖出价。
- 若先触发止损，记录该时点；不会因为后面又涨了就改成成功。
- 若始终没出现正净溢价，按最晚退出时间计算结果。

**你还没指定“没溢价时怎么办”。本版暂用净止损−1.5%、最晚10:30退出作为研究默认值，不代表你已经确认这些实盘规则。**

费用默认值仅为占位估计：往返费用0.20%，买入滑点0.05%，卖出滑点0.05%。必须根据实际券商收费、最低佣金、每笔金额和成交条件修改。这不是法定费率说明，也不是对实际成交费用的精确计算。

当前研究价和分钟收盘价都不是券商真实成交。真实买入价不同会改变溢价门槛；真实成交与执行偏差需要你单独核对。涨停、跌停、停牌、隔夜跳空、除权除息等也可能使这套代理结果失真。平直分钟条触发退出时保守标记为execution_unverified，不计入胜负学习。

## 如何复盘并“吸取经验”

1. 每次14:30运行，只读取**上一交易日**最终发布的候选。星期一按交易日历找上周五，不按自然日减1。上一交易日无候选或没运行，不拿更早的股票冒充T+1。
2. 拉取今天09:31—默认10:30分钟线，重放上述退出规则；缺失分钟线/停牌写pending_data，既不算成功，也不算失败。
3. 同时保存成功与失败样本。失败定义为规则退出时净收益没有超过目标，不要求先跌2%才算失败。早上有退出机会、下午下跌的股票不会仅因下午价格下跌就被判失败。
4. 统计入选时的涨幅过高、MA10乖离、高换手、尾盘走弱、均价偏离、市场偏弱等特征；这些是相关线索，不能证明真实下跌原因。公告、事件等原因须另查。
5. 至少30条有效样本、跨10个入选日期；单特征组与对照组各至少12条并各跨5天后，才可能生成小幅风险扣分。按日期均衡统计，避免同一天的市场冲击主导结论。全部学习最多扣1分，不凭昨天一只股票的结果直接“封杀”或“追捧”一种形态。
6. 最近60个有样本的入选交易日为滚动窗口。重复运行不重复累计同一只股票的同一天记录；退出规则/费用改变后不会混用旧策略样本。

`apply_learning=true`表示达到门槛后应用风险扣分；设为`false`可先只看建议，不改变评分。**这种规则更新未经过样本外验证，不保证能提高收益。**

复盘样本基于“最终候选 + 研究入场价”，并不代表你实际买入过这些股票。学习统计也不是账户实盘胜率。原始分钟数据保存在raw目录，便于以后逐笔核验。若你漏跑一天，旧候选不会在后天被误记成T+1；本版本不会自动补齐所有历史缺失复盘。

## 选股规则与原邮件的变化

保留AkShare数据路线：东财全市场快照和1分钟行情，腾讯历史日线。为适配20分钟预算，先缩小到最多60只，再做深查，最后只复核最多8只；不声称穷尽全市场。

新评分最高10分，重心在分时均价、尾盘15分钟动量、距离日高回撤、成交额、换手率、短均线及当日涨幅。日线只用上一交易日及更早的数据，再用当时分钟价估算当前短均线；不把尚未产生的当日收盘价当已知信息。原脚本的行业/概念板块成份映射不再是必要依赖，也没有把缺失板块资金流伪造成零。

默认只纳入沪深主板，排除ST、退市标记、上市历史不足40根日线、成交额不足1亿元等。创业板需有相应权限且自行将allow_chinext设true。科创板和北交所未纳入。市场上涨占比低于35%时本轮空仓观察。各项数值都是**未完成历史验证的启发式研究参数**，可以修改，不能把它们当成已经验证的交易优势。

## 修改参数

编辑同目录config.json；修改后下次运行生效。engine.py也保留scan_market入口供开发使用。执行输出在CLI上提示报告路径。

重要参数：target_net_pct、stop_net_pct、exit_time、round_trip_cost_pct、entry_slippage_pct、exit_slippage_pct、apply_learning、min_amount_yuan、min_score、shortlist_size。

交易日历由tool_trade_date_hist_sina获取并缓存，**会检查覆盖日期**。如果接口返回的日历仍停留在去年，程序停止选股；不会用“周一到周五”冒充交易日。可把核对过的交易日JSON数组文件绝对路径填入calendar_file。格式示例`["2026-10-28", "2026-10-29", "2026-10-30"]`只展示格式；实际应维护完整、正确且覆盖运行日期的交易日历。
