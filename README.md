
# A股猎手｜新浪主源・腾讯备用版

## 一、项目介绍

A股猎手是一套用于沪深A股市场扫描、技术指标分析、股票评分和历史复盘的研究工具。

本项目采用手动运行模式，不设置自动定时任务。

主要功能：

- 扫描上海证券交易所和深圳证券交易所A股。
- 包含创业板、科创板。
- 默认排除ST及退市整理类股票。
- 新浪行情作为实时行情主数据源。
- 腾讯行情作为备用数据源。
- 获取历史日线数据并计算技术指标。
- 根据技术面、价格位置、成交量和市场环境进行综合评分。
- 输出综合评分靠前的候选股票，默认展示前三名。
- 保存历史推荐、运行报告和学习记录。
- 对过去推荐的股票进行后续表现复盘。

## 二、数据来源

| 数据项目 | 数据来源 |
|---|---|
| 实时行情主源 | 新浪财经 |
| 实时行情备用源 | 腾讯财经 |
| 历史日线 | 腾讯财经 |
| 技术指标 | 本地计算 |
| 历史学习记录 | reports目录 |

重要说明：

1. 不使用东方财富作为行情数据源。
2. 不使用AkShare。
3. 不保证行情接口始终可用。
4. 如果数据获取失败，程序应报告错误，不应伪造行情或虚构选股结果。
5. 委比、内外盘、主力资金流等数据，只有在接口真实提供时才能参与分析；无法取得时应标记为不可用。

## 三、项目文件说明

| 文件 | 作用 |
|---|---|
| hunter.py | 新版主程序，负责扫描和选股 |
| data_source.py | 新浪、腾讯行情数据接口 |
| indicators.py | 技术指标计算 |
| learning.py | 历史推荐复盘和学习 |
| config.json | 选股参数和运行配置 |
| requirements.txt | Python依赖 |
| test_engine.py | 自动化测试 |
| .github/workflows/manual-scan.yml | GitHub手动运行工作流 |
| reports/ | 扫描报告和学习数据 |

注意：

新版扫描入口为 hunter.py。

旧版 engine.py 暂时保留作为历史文件，不作为新版扫描入口。

## 四、GitHub运行方法

1. 打开GitHub项目。
2. 进入 Actions。
3. 选择“A股猎手-手动运行”工作流。
4. 点击 Run workflow。
5. 选择 ashare-1430-test 分支。
6. 点击确认运行。

运行前会先执行自动化测试。

测试通过后，才会启动新版全市场扫描。

如果测试或行情获取失败，请打开对应任务查看日志。

## 五、报告和学习记录

扫描结果保存在 reports/ 目录。

主要包括：

- 每次运行的扫描报告。
- 股票候选名单。
- 行情数据源状态。
- 历史推荐记录。
- 历史复盘结果。
- 学习记忆和形态统计。

GitHub Actions运行完成后，会尝试将 reports/ 中新增或更新的文件提交回本次运行的分支。

请不要随意删除 reports/ 中的学习记录，否则会影响历史复盘。

## 六、配置修改

所有主要选股参数集中在 config.json。

可以调整：

- 候选股票数量。
- 最终推荐数量。
- 最低评分。
- 股票价格范围。
- 成交额门槛。
- 日涨跌幅范围。
- RSI参数。
- MACD参数。
- 均线参数。
- 学习和复盘参数。
- 止盈止损参考值。

修改配置后，下次运行自动采用新参数。

## 七、风险提示

本项目只提供股票研究和筛选参考：

- 不连接证券账户。
- 不自动买卖股票。
- 不保证推荐股票上涨。
- 综合评分不代表实际胜率。
- 止盈止损参数仅供参考，不代表自动交易指令。
- 盘中行情可能存在延迟、缺失或接口波动。

投资决策应结合市场环境、公司基本面和个人风险承受能力。
